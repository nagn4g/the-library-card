A short poem about permission: a borrowed library card, and a yes written years before it was asked for.

> I asked to borrow your library card. You signed the back and said, take what you need. I carried home a stack of other people's lives, and on the last page of the last one I found a note in my own handwriting — a yes I wrote years before I asked.

The speaker asks for the card, is given it, carries books home, and finds a yes in their own handwriting.

The poem is 246 Unicode code points and 248 UTF-8 bytes. The program writes it to `/output/entry.txt` with no trailing newline.

## Run it

```sh
node main.ts
```
